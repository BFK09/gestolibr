# GESTOLIBR — Gestion de librairie-papeterie

Application web installable (PWA) qui fonctionne hors ligne : catalogue, réception de marchandise,
caisse avec paiement partagé, inventaire, sauvegarde et tableau de bord. Monnaie : FCFA.

Voir `LISEZMOI.md` pour le rôle de chaque fichier et les commandes.
